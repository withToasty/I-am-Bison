# Graphics Reference

## Bison visual target

2026-09-28 に作成したローポリ・バイソンのモーションスタディを、**I AM BISON のキャラクター造形の基準イメージ**とする。

![Low-poly bison reference](assets/bison-low-poly-reference.jpg)

### 造形の要点

- ローポリゴンで、大きな面の切り替えが見える。
- 前半身・肩を大きく重くし、後半身へ向かって細くする。
- 頭部と脚先は胴体より暗いブラウン。
- 角は明るいアイボリー系。
- 写実的に細かくしすぎず、シルエットだけでもバイソンと分かる。
- 上から／斜め後方から見たゲーム画面でも、肩の盛り上がりと前後の重量差を残す。

### 実装時の扱い

この画像は完成アセットそのものではなく、今後の3D/2Dキャラクター制作で外してはいけない**アートディレクション基準**。
円や単純な仮図形を最終表現とせず、このシルエットとローポリ感へ寄せていく。
