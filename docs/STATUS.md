## 開発計画・古い資料との違い

- 初期仕様 `docs/specification.md` の終了条件は「active herd countが0」。現在のGameSceneは、それに加えて「先頭個体が突破できない岩・柵等に衝突」でも終了します。これは[先頭個体を導入したコミット](https://github.com/withToasty/I-am-Bison/commit/2990a19dfdba0af1545a04c1d823c0e065921243)で意図的に変更された挙動です。
- 既定モードに90秒の強制終了はありません。初期仕様の約90秒は初心者の生存時間の目安です。
- EncounterDirectorの「前方に生成／後方を削除」方式は現在使っていません。WorldGridが自由な戻り移動に対応します。
- v0.2時点の「6種類の遭遇」「ENCOUNTERS/ACTIVEを確認」というPR説明・検証記録は当時のものです。
- 岩は永久に破壊不能ではありません。現在は群れの規模で破壊できます。
- 障害物は柵だけでなく倒木・氷も実装済みです。v0.3設計時の対象外項目から進展しています。
- 仕様書のSTOP条件や実装用プロンプトは各段階の履歴であり、現在地を未着手に戻すものではありません。
- 基本ゲームとM-G1〜M-G4はすでにmainに統合され、GitHub Pagesへのデプロイ記録があります。今後の受け入れ確認は、未統合コードのマージ判断ではなく、現行版の品質確認として行います。

## M-G5の受け入れ手順

新機能追加の前に、以下を同じビルドで確認して記録してください。

1. 通常セルで仲間を一部だけ加入させ、岩・柵を破壊する。
2. セルがアンロードされる距離まで離れて戻る。加入済み個体と破壊済み障害物が復活せず、未加入個体と未破壊障害物は残ることを確認。
3. 牧場でも離脱・再訪を繰り返し、加入個体が重複せず発見数が重複加算されないことを確認。
4. 草原から森林・峡谷・雪原へ進み、戻り移動でも地形が再現されることを確認。
5. 1／50／100頭以上で旋回・セル境界通過・ゲームオーバー・再試行を確認。先頭個体の衝突による終了条件も含める。

記録項目: 日時（日本時間）、対象SHA、URL、端末、OS／ブラウザ、群れ数、所要時間、操作手順、期待結果、実際の結果、エラー・引っ掛かり。
