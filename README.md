# I AM BISON / 僕はバイソン

群れを増やしながら自由に移動する、Vite + TypeScript + Phaser製のブラウザゲーム。

## 現在地

基本ゲーム（M0–M10）、v0.2の操作感改善、v0.3の自由移動ワールド（M-G1〜M-G4）のコードを実装済みです。
最新の実装範囲・未確認事項・次の作業は [開発状況](docs/STATUS.md) を参照してください。
「実装済み」は実機での品質確認完了を意味しません。

## 起動・確認

Node.jsはVite 7の要件を満たす環境を使用してください。

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

- PC: 左右矢印キー、またはA/Dを長押しして旋回。
- スマホ: 画面の左半分／右半分を長押しして旋回。
- 入力を離しても移動は継続。Uターン・戻り移動も可能。
- 野生の仲間に近づくと群れに加入。大きな群れは曲がりにくくなります。
- 障害物は群れの規模に応じて突破可能。川では減速し、隊列が崩れやすくなります。
